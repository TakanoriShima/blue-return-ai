# 構造 Inspector（実データの構造確認ツール）

実データ（`data/` 配下の Excel・CSV）の **値を表示せずに**、パーサー実装に必要な構造だけを確認するツール。本人がローカルで実行する。Claude Code は実データに対して実行しない。

```bash
python -m blue_return_ai.inspect_structure excel <ファイル> [オプション]
python -m blue_return_ai.inspect_structure csv <ファイル> [オプション]
```

## デフォルトで表示するもの（値は表示しない）

| 種類 | 表示内容 |
| --- | --- |
| Excel | シート数、シート名、表示状態、max_row / max_column、結合セル範囲、非表示の行・列、非空セルの「番地・型・数式かどうか」 |
| CSV | 推定文字コード、BOM の有無、改行形式、区切り文字、行数、空行数、列数の分布、ヘッダー候補行、ヘッダーより前の行の列数、列ごとの値の種類（日付らしい / 整数らしい / 文字列 等）、日付の書式（数字を 9 に置換）、数値の特徴（カンマ・符号の有無等） |

- ファイル名は表示しない。シート名は表示されるため、共有前に取引先名等が含まれていないか確認する。
- エラーには例外の種類だけを表示する。

## オプション

| オプション | 内容 | 値の表示 |
| --- | --- | --- |
| `excel --with-format` | 表示形式の種類（date / number 等）と、数式セルのキャッシュ値の型 | なし |
| `excel --find-text TEXT` | 指定した文字列と完全一致するセル番地（例：`--find-text 小計`）。複数指定可 | 指定した文字列のみ |
| `excel --sheet NAME\|N` | 対象シートを限定 | なし |
| `excel --cells A1,B2` | 指定セルの型・表示形式 | なし |
| `excel --cells A1,B2 --show-values` | 指定セルの値 | **あり（警告を表示）** |
| `excel --show-formulas` | 数式の中身 | **数式内の値を含む可能性（警告を表示）** |
| `csv --header-row N` | N 行目をヘッダーとして列番号付きで表示 | **あり（警告を表示）** |
| `csv --show-row N` | N 行目の値 | **あり（警告を表示）** |
| `csv --encoding` / `--delimiter` | 文字コード・区切り文字を指定 | なし |
| `--sha256` | ファイルの SHA-256 | なし |
| `--output FILE` | 結果を JSON で保存（リポジトリ内では `data/` 配下のみ。上書きしない） | 指定内容による |

値を表示するオプションの出力には実データが含まれる可能性がある。**Claude Code 等の外部 AI に貼り付けない。** 共有する場合は、人間が個人情報を含まないことを確認してから、必要な部分だけを共有する。
